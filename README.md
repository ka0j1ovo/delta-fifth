# Delta Fifth（四角洲不动）· 撤离射击（网页版）

一个用 **Three.js (WebGL)** 写的浏览器 3D 第一人称「四角洲不动（Delta Fifth）」撤离射击游戏：

**进入地图 → 击杀 Bot / 开箱搜刮物资塞满背包 → 走到撤离点活着带出 → 存入仓库。**

> 完全离线可玩：Three.js 已本地打包在 `js/three.min.js`，无需联网。

## 如何运行

- **方式一（最简单）**：双击 `start.bat`（会尝试起本地服务器并打开浏览器，否则直接打开 `index.html`）。
- **方式二**：直接用任意浏览器打开 `index.html`。

## 操作说明

### 电脑

| 按键 | 功能 |
| --- | --- |
| 鼠标移动 | 视角 |
| 左键 | 射击 |
| WASD | 移动 |
| 右键（长按） | 开镜 |
| R | 换弹 |
| 1 / 2 / 3 / 4 / 5 | 切换武器 |
| F | 开箱 / 交互 |
| Tab（长按） | 打开背包（可拖拽物品放入保险箱） |
| Shift | 静步 |
| Esc | 释放鼠标 |

### 手机 / 平板（横屏手游键位）

检测到手机或触屏设备后自动进入手游模式，竖屏会显示「请横屏握持」提示，横屏开局即使用手游键位：

- **左侧摇杆**：移动，向上推前进；摇杆右侧为「静步」切换键。
- **右侧空白区域**：滑动瞄准，支持一边拖动瞄准一边按开火（多点触控）。
- **右下开火**：按住全自动武器连发，单击半自动武器单发。
- **开镜 / 换弹 / 跳跃 / 开箱（补给）**：环绕在开火键周围；靠近箱子时交互键变为「长按开箱」，在武器商店范围内点击武器快捷栏即可购买。
- **武器快捷栏**：底部 1–5 号位，已拥有时切换武器，在商店范围内会显示价格。
- **顶部快捷**：打开背包、暂停。手机背包采用「先点物品，再点目标格」的方式移动物品，并可丢弃选中物。
- **暂停 → 自定义键位**：所有 gameplay 键位都支持拖动定位、双指捏合或「＋ / −」缩放；按「恢复默认」可复位。布局自动保存在浏览器 `localStorage`，并且会避开刘海 / 挖孔 / 底部手势条等安全区。

> 调试时可用 `?touch=1` 强制开启手游键位、`?touch=0` 强制关闭。

## 玩法

- **目标**：搜刮 → 战斗 → 撤离。进图塞满 9 格背包，到地图中心撤离点站 10 秒活着带出。撤离时间线：开局 60 秒内无法撤离；60~90 秒付费撤离（需 500 哈基币，不足则无法撤离）；90 秒后免费；第 7 分钟提示即将结束；第 8 分钟起再次付费撤离（持续 120 秒）；10 分钟耗尽未撤离即失败。付费撤离按品质低到高删除价值 500 的物品，超出部分转为点数。
- **死亡惩罚**：死亡则本局背包全丢；放入「保险箱」的物品可带出（保险箱靠累计消费点数解锁，最多 4 格）。
- **货币**：局内「哈基币」在武器商店买枪 / 血包（每局清零）；持久「点数」用于解锁仓库格子、购买展示柜皮肤、强化开局装备。
- **开局进入方式**：eco 进入（50 血 · 免费）或买票进入（100 血 · 200 点），可选购护甲 / 血包 / 开局武器。
- **品质与崭新度**：物品带出后记录带出的北京时间，并随机获得 0~1 五位小数「崭新度」（越大越新、越贵：1.0 崭新 / 0.0 完全磨损）；珍贵展示柜物品可点开「检视」查看详情。
- **精英 Bot**：游戏 5 分钟后刷新（1000 血、掉落更好）。

## 技术说明

- 纯原生 JS + Three.js，无构建工具，无外部依赖。
- 命中判定用 Three.js `Raycaster`（射线检测），爆头通过区分头部 / 身体 mesh 实现。
- 音效为 Web Audio 合成 + 本地击杀音效（`audio/`）。
- 存档保存在浏览器 `localStorage`（可在首页导出 / 导入 JSON）。
- 手机适配使用 Pointer Events + 多点触控；键位图标为内联 SVG / CSS 手绘，无外部图片。
- 手游模式：`(pointer: coarse)` + 触点 + Mobile UA 自动识别；支持 Fullscreen + Screen Orientation API 请求横屏锁定（浏览器不支持时回退到竖屏提示）。
- 键位布局独立保存在 `localStorage` 的 `sdfc_touch_layout_v2`，不会影响存档数据。
